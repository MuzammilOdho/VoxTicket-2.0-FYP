Return window: 30 days from the delivery date.
Eligibility: the item must not be marked final sale, must be in returnable condition, and must have remaining returnable quantity not already returned.
Process: the returned item must be received by the warehouse and pass inspection before a refund is issued.
Outside the window: returns are not accepted once the 30-day window from delivery has passed.
Partial returns: a customer may return part of a multi-item order; only the returned items are refunded.
